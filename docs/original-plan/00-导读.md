# 第0章 怎么用这份详细实操版：先读这 5 分钟

这份文档不是「规划思路」，而是**执行手册**。上一版《AI 学习规划书》告诉你「该学什么、该做什么」；这一版把每个环节拆到**可以照着敲**的粒度：装什么、命令是什么、代码怎么写、跑出来应该看到什么、指标达到多少才算过、报错怎么解。

读完第 0 章，你应该能回答三个问题：**我从今天开始做什么**、**每周的产出是什么**、**卡住的时候去哪一章找答案**。

## 0.4 六条执行铁律

1. **每天只做当天的事。** 本版课表按天排好了，不要今天想「先把整个 Transformer 看完」——那是拖延的另一种形式。
2. **每周必须有推到 GitHub 的提交。** 没有产出的一周等于没发生。第 5、6 章每周都给了「本周交付物」勾选清单，那就是验收标准。
3. **先跑通，再优化。** 任何项目先做出能运行的丑版本，再谈指标、再谈工程化。禁止「先读三个月书再动手」。
4. **一切以数字结尾。** 显存峰值、延迟、准确率、召回率、成本——简历上没有数字的项目等于没做。
5. **8G 不是瓶颈，方向错了才是。** 遇到跑不动，先按第 2 章的「缩小模型 / 缩小数据 / 冻结参数 / 数据蒸馏」四条路走，而不是买卡。
6. **工具链半年不换。** 主线工具在第 4 章已经定死（uv、PyTorch、transformers + peft + trl、llama.cpp、LangGraph、FastAPI）。新框架只做了解，不动主线。

## 0.5 怎么读这份文档里的元素

- **代码块**：右上角有「复制」按钮。命令块里会写清执行位置，例如「在 PowerShell 执行」或「在 WSL2 Bash 执行」，两者不能混。
- **预期输出**：代码块后面通常会告诉你「应该看到什么」。看不到就是这一步没成功，别往下走。
- **勾选框**：`任务` 形式的条目可以直接勾选，进度存在本机浏览器（localStorage），左侧进度条同步更新。换电脑不跟随，所以**重要的进度同步记到 GitHub Issue 或自己的周报里**。
- **提示框**：
  - 蓝色 `tip` = 更省事的做法
  - 绿色 `ok` = 验收通过标准，达到了才算这一步做完
  - 黄色 `warn` = 常见坑，先看能省你两小时
  - 红色 `danger` = 会删数据、会花钱、会覆盖文件的操作，做之前停三秒

## 0.6 三个必须提前知道的真相

:::warn 真相一：真正卡住应届生的不是 8GB 显存
卡住人的是「没有可讲的项目」和「只会调 API」。8GB 完全够跑 7B/8B 的 4bit 微调、够做完整 RAG、Agent 和部署工程。你的 4060 能覆盖本规划 **90% 以上的动手环节**，剩下不到 10%（全量微调、大规模 RL）按规定租云或换思路即可。
:::

:::warn 真相二：四个方向不在同一层，不是四选一
NLP/LLM 是**技术底座**，Agent 开发是**技术外壳与工种**，边缘部署与推理优化是**能力差异化**，AIOps 是**垂直落地场景**。正确的问法是「底座选谁、主攻选谁、差异化选谁、场景选谁」，本版给的配比是 35% / 30% / 20% / 15%。
:::

:::warn 真相三：岗位数量与门槛是反相关的
「大模型应用 / Agent」岗位最多、门槛最友好、竞争者最多；「LLM 算法」岗位少、薪资高但要求论文与实习；「边缘部署 / AIOps」岗位少、竞争者也少。你的最优策略是**主投应用与工程岗、兼投算法岗**，用部署能力做溢价。
:::

## 0.7 看一眼市场数据，然后冷静解读

| 数据 | 来源口径 | 冷静解读 |
| --- | --- | --- |
| AI 应用开发工程师需求占比约 53.9%，居 AI 岗位首位 | 招聘平台公开的校招 AI 人才洞察报告 | 这正是「Agent + RAG 工程」对应的岗位，说明主攻方向选对了；但绝对数量仍少于后端/前端，投递量必须够大 |
| 企业最看重「数学与统计基础」（约 58.9%）与「机器学习理论与实战」（约 46.5%） | 同上 | 只会写 prompt 和调框架容易被替代，所以第 5 章 W3、W4 的数学与经典机器学习不能跳 |
| 大模型算法岗月薪中位值约 2.7 万，数据标注类岗位约 0.9 万 | 同上 | 差距不在「碰不碰 AI」，而在你是**设计系统/调模型**的人还是**标数据/套模板**的人；本规划所有项目都要求量化指标就是为了站到前一侧 |

:::warn 三个不要被带偏的地方
- 中位值会被头部大厂拉高，普通应届生实际到手可能低 20%–40%，不要拿 2.7 万当心理预期。
- 「近三成企业布局 AI」不等于「三成岗位是 AI」，投递基数（秋招 80–150 家）不能少。
- 应用层存在同质化与泡沫风险；贴近硬件与成本的**推理部署与优化**抗风险能力更强，这也是本规划坚持把它列为差异化技能的原因。
:::
